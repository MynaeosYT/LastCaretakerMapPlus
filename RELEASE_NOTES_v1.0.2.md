# The Last Caretaker Map Plus v1.0.2

This data-correction update follows a complete in-game review of all 104 samples.

## Changes

- Corrected the POI anchor and top-platform description for Sample #046
- Renamed Sample #051 to `Closed Door` and moved it to the underwater Seed Reserve 01 POI
- Clarified the Human Seed insertion shown by Sample #124 inside underwater Seed Reserve 11
- Corrected the underwater state for Sample #647 and every Holo Memory assigned to an underwater Grave
- Added validator rules to protect the confirmed names, locations, precision, and underwater states
- Updated the sample catalog and uncertainty notes

Existing collected status is preserved because all stable sample IDs remain unchanged.
