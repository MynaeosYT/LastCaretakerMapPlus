# The Last Caretaker Map Plus v1.0.1

This update improves map readability and replaces the previously bundled POI artwork with the original in-game map icons supplied for this fan project and used with permission from Channel37.

## Changes

- Replaced all 22 location-type icons with the official Channel37 POI icons
- Added the official whale icon for Project Jonah world events
- Improved the size and presentation of Project Jonah markers
- Arranged related non-exact markers around their associated POIs to reduce overlap
- Consolidated two duplicate Transposium Teddy theater passage records
- Extended icon and secret-data validation for the new assets and consolidated record
- Updated third-party notices to distinguish the permitted game icons from BSD-licensed project code

All personal progress remains in the browser's local storage and is preserved when updating from v1.0.0.

The Last Caretaker Map Plus is an unofficial fan project and is not affiliated with or endorsed by Channel37 Ltd. The original map was created by The1Killer; the Plus edition and additional datasets are maintained by Mynaeos.
