# Changelog

All notable changes to The Last Caretaker Map Plus are documented here.

## 1.0.0 - 2026-08-09

First public-ready Map Plus release.

### Added

- 104 searchable samples across Holo Memories, Cave Paintings, and Rock / Wall Paintings
- 37 Paint Schemes with can collection and unlock progress
- Quest starts, optional objective markers, and Project Jonah world events
- Secrets and gated areas with spoiler-conscious hint and solution reveals
- Shared marker legend and grouped sidebar navigation
- Per-location visited/cleared status and personal notes
- Complete local backup and restore for Plus progress and preferences
- Source, precision, and known-limitation documentation

### Changed

- Unified the public interface and visible dataset text in English
- Standardized sidebar controls, category headers, and collapsible lists
- Locations opens to its filters by default while location lists remain collapsed
- Improved keyboard navigation, responsive layout, and small-screen controls
- Updated branding and credits for the Plus edition

### Removed

- Google Analytics and related tracking code
- Optional in-game cloth-map overlay and its image asset
- Runtime CDN dependencies

### Data notes

- Community positions use `exact`, `poi`, or `approximate` precision labels
- Sample 694 uses the Courier Sieve Node Facility POI anchor at `169:-2`
- Samples 051 and 059 intentionally retain `UNKNOWN` names because available sources do not document their English in-game names
