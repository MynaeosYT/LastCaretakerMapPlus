# The Last Caretaker Map Plus v1.0.3

This is the final regular data refresh for the legacy map. Six newly verified or completed findings were checked directly in game by the map author on August 20, 2026.

## Changes

- Resolved the Habitat Node 04-7 research lead as a hidden underwater support container
- Resolved the Habitat Node 05-14.5 research lead as a hidden underwater support room
- Added separate upper and deep underwater support rooms at Habitat Node 09-4
- Added a second, outer underwater room at Refuel Outpost Theta without changing the existing central oil room
- Added the multi-stage support-vent hidden chamber route at Exodus Station as one Secret
- Updated the Secret overview to 29 records: 27 accessible findings and 2 remaining research leads
- Added validation for aggregate counts, the six directly verified records, and URL-free direct in-game verification
- Made the displayed research-lead count derive from the data

No exact entrance coordinates, directions, quantities, official room names, or story interpretations were added where they were not known. Existing Secret IDs and saved user progress remain intact.

The Last Caretaker Map Plus remains available as a stable legacy map and reference dataset. Future data development continues in the successor website project.
